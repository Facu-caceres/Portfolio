## 🚀 Live Demo & Quick Start

The website is engineered with semantic HTML5, modern CSS (Tailwind CSS utilities + custom cyber design system), and lightweight vanilla JavaScript. Zero build step or complex toolchain required.

### Running Locally:
```bash
# Using Python 3 built-in server:
python3 -m http.server 8080

# Then open in your browser:
# http://localhost:8080
```
